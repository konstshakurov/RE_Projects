# Запрос на концепцию

Ты - компания заказной разработки АО СимбирСофт. 1500 человек, 25лет, основная услуга аутстафф. 
Производство включает специалистов Бизнес и системных аналитиков, архитекторов, бэкенд, фронтед, диайнеров, мобильных разработчиков, DevOps, SDET, QA и др.  

Необходимо разработать концепцию проекта для компании Лемана - российская сеть гипермаркетов и интернет-магазин товаров для строительства, ремонта и обустройства дома. 
У компании есть интернет магазин в виде мобилки и веб сайта. Компания работает сфиз и юр лицами. 

Идея проекта - разработать проект для оказания таких услуг как: 
уход за садом
аренда оборудовани
ремонт и стройка

В мобильном приложении существующего интернет магазина создать переход на раздел "Услуги". 
В новом экране услуг отобразить 3 кнопки/краточки услуг:
уход за садом
аренда оборудовани
ремонт и стройка

При клике на услугу "Уход за садом" перейти на экран "перечень услуг", который содержит перечень: 
Уборка участка
Ландшафтные работы
Озеленение

При клике на "уборка участка" открыть экран, на котором  дать пользователю выделить нужные работы из перечня:
Скашивание травы и борьба с сорняками.
Спил деревьев, кустарников и удаление поросли.
Сбор и вывоз мусора, листвы, веток.
Корчевание пней.
Выравнивание земли.

Внизу экрана отразить итоговую стоимость за час работ.

Условная структура всего проекта: 
- Фронт для клиента (разделы в мобилке, на сайте) (заказывает, получает счет, оплачивает)
- Фронт для авторизованных мастеров на мобилке (авторизация, календарь заказов, карточка заказа, отправка результата)
- Фронт для неавторизованных мастеров (раздел на сайте, мобилке "стать сертифицированным мастером от ЛемнаПРО")
- Фронт для админа (список мастеров, карточка мастера, заказы в виде календаря, настройка)
- Бэкенд (сразу с логикой автоматического распределения заявок как в Яндекс Такси)
- Интеграции бэка с учетными системами (1С и др.) 

Разработай подробную концепцию проекта в формате MD, включи в нее дополнительнно описание архитектуры, перечень всех необходимых экранов для всех UI.
Задавай вопросы для уточнений.
